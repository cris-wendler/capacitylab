Five AI agents review a database capacity decision

A database engineer, an application owner, a reliability engineer, a FinOps analyst and a tenant representative, simulated by a large language model or by scripted rules, look at the same decision. Each sees the evidence its role gives it, asks for checks, and takes a position. Code does the maths and checks every number they quote. The result is a written record of what each agent recommends, what is still disputed, and what nobody has measured yet.

Review rounds

Roles cite evidence, request checks (capacity model, cost, index tests, rewrite checks, lab load tests), and challenge each other. Numbers they state must appear in what they cite.

3

Decision record

Final positions, open disagreements, missing evidence, and a log you can replay to verify every check.
